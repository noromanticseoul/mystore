# PRD v1 실무자 피드백 기록 (예상 피드백)

> 이 문서는 실제 인터뷰가 아니라, 패션 업계 실무자 관점에서 **예상되는 반응을 시뮬레이션해 기록**한 것입니다. 각 역할의 업무 방식(출점 검토 절차, 보고 양식, 현장 조사 관행)을 기준으로 PRD v1을 검토했다고 가정했습니다. 실제 검증이 필요한 항목은 마지막 표에 별도로 표시했습니다.

- 검토 대상: `PRD_의류창업입지_v1.md`
- 작성일: 2026-11-19
- 반영 결과: `PRD_의류창업입지_v2.md`

## 1. P1 · 편집숍 점주

> "어디가 뜰지보다, **내가 감당할 수 있는 동네 중에** 어디가 나은지가 궁금하다."

| # | 피드백 | 심각도 |
|---|---|---|
| 1-1 | 서울 전체 Top 10은 대부분 내가 들어갈 수 없는 대형 상권일 것. **자치구·동 필터**가 먼저 있어야 한다. | 높음 |
| 1-2 | 임대료가 없으면 결정을 못 한다. 데이터가 없다면 **없다고 분명히 쓰고**, 확인할 곳을 알려 달라. | 높음 |
| 1-3 | 16개 슬라이더는 너무 많다. 나는 "요즘 뜨는 곳 위주 / 안정적인 곳 위주" 정도만 고르고 싶다. | 높음 |
| 1-4 | "수요 추세 0.97" 같은 숫자는 의미를 모르겠다. **"작년보다 매출이 12% 늘었음"**처럼 말해 달라. | 중간 |
| 1-5 | 주변에 옷가게가 이미 몇 개인지가 제일 먼저 보고 싶다(현재 기준). | 중간 |

## 2. P2 · 리테일 MD

> "상승 여부보다 **얼마나 큰 시장이 얼마나 움직이는지**를 같이 봐야 한다."

| # | 피드백 | 심각도 |
|---|---|---|
| 2-1 | 오른다/안 오른다만으로는 부족. **매출 규모**가 너무 작은 상권은 5% 올라도 의미가 없다. 최소 매출 규모 필터가 필요하다. | 높음 |
| 2-2 | 의류는 **주말·저녁 유동**이 중요하다. 상세 화면에 평일/주말, 저녁 비중을 보여 달라. | 중간 |
| 2-3 | 카페 관계가 "없음"으로 나왔으면 그대로 보여 주는 게 낫다. 억지로 연결하면 오히려 신뢰가 떨어진다. | 중간 |
| 2-4 | 후보 2~3곳을 **나란히 비교**하는 화면이 있어야 내부 회의에서 쓴다. | 높음 |

## 3. P3 · 점포개발 과장

> "임원 보고에 쓰려면 **근거가 고정된 숫자**여야 한다. 내가 슬라이더를 만져서 나온 순위는 보고서에 못 쓴다."

| # | 피드백 | 심각도 |
|---|---|---|
| 3-1 | 검증된 기본 순위와 내가 조정한 순위가 **확실히 구분**되어야 한다. 조정 순위에는 "검증 전" 표시가 필요하다. | 높음 |
| 3-2 | "13개 분기 중 Top 10이 평균 8.2개 올랐다"는 좋다. 다만 **최악의 분기**가 몇 개였는지도 같이 보여야 리스크 설명이 된다. | 높음 |
| 3-3 | 후보 리스트를 **CSV로 내려받거나 인쇄**할 수 있어야 한다. | 중간 |
| 3-4 | **하락 가능성이 높은 상권**도 알려 주면 기존 매장 점검에 쓸 수 있다. | 중간 |
| 3-5 | 예측 대상 분기와 데이터 기준일이 화면 맨 위에 항상 보여야 한다. | 낮음 (v1에 반영됨) |

## 4. P4 · 상권분석 컨설턴트

> "숫자를 보여 주는 것보다 **어디까지 믿어도 되는지**를 보여 주는 게 더 중요하다."

| # | 피드백 | 심각도 |
|---|---|---|
| 4-1 | 슬라이더로 과거 성적을 최대화하면 과적합된 조합을 고르게 된다. 조정 결과에 **기준 대비 차이와 분기별 승·패**를 같이 보여 달라. | 높음 |
| 4-2 | 등급 "높음"이 실제로 몇 % 확률인지 한 줄로 설명해 달라 (보정 확률 기준). | 중간 |
| 4-3 | 반경 기준(500m)은 큰 상권에서 과소 집계된다. 상세 화면에 **측정 기준**을 작게 적어 달라. | 낮음 |
| 4-4 | 외부 데이터의 효과가 작았다는 결과를 숨기지 말고 성적표에 그대로 표시하는 편이 신뢰를 준다. | 중간 |
