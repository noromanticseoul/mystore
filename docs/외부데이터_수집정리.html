미수집
  • 네이버 데이터랩·검색: 개발자센터에서 해당 API 신규 등록 불가로 키 발급 실패. 수집 스크립트는 준비 완료
  • 인스타그램 해시태그: 공개 API 없음. 비즈니스 계정·앱 심사 필요, 기간별 게시물 수 미제공. 크롤링은 약관 위반으로 배제
해석 주의
  • 구글 트렌드는 비공식 API로 요청 제한(429)이 심해 수집 진행 중. 검색량이 작은 동은 0으로 반올림
  • 동 키워드는 행정동 단위라 같은 동 안 여러 상권이 같은 값
  • 위키 조회수는 관심도 대리 지표로, 소비와의 직접 관계는 약함
  • 반경 매칭은 중심점 기준이라 관광특구 등 큰 상권은 영역 일부만 반영
  • 카카오·상가정보 점포 수는 현재 시점 값으로, 과거 학습에 사용 불가
