# 어디입게 · 서울 의류 상권 전망

의류 매장 예비 창업자와 점포개발 실무자를 위한 다음 분기 상권 전망 서비스입니다. 서울 의류 상권 817곳의 2026년 3분기 매출 상승 가능성을 보여 주고, 요인 비중을 직접 조정해 과거 13개 분기 성적을 즉시 확인할 수 있습니다.

- 서비스: `index.html` (데이터 내장 단일 파일, 서버 불필요)
- 기획 문서: `docs/PRD_의류창업입지_v1.md` → `docs/PRD_v1_실무자_피드백.md` → `docs/PRD_의류창업입지_v2.md`
- 데이터 수집 정리: `docs/외부데이터_수집정리.html`
- 발표 자료: `docs/어디입게_최종발표.pptx` (본편), `docs/데이터가공편/` (수집·정제·결합·피처 생성까지)

## 기준
- 기본 순위: v5 블렌드 (추세 유지 규칙 순위 + LightGBM 순위 평균). 13개 분기 롤링 백테스트 AUC 0.661, Top 10 적중 평균 8.23.
- 외부 데이터(검색·지하철·버스·날씨·현재 점포 수)를 추가한 모델은 검증 게이트를 통과하지 못해 참고 지표로 제공합니다 (Top 10 8.46으로 높지만 차이가 유의하지 않고 분기별 편차가 큼).
- 임대료·권리금은 포함하지 않습니다.
